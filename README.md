# 🚗 AI-Powered Risk Score Engine

An intelligent incident detection and analysis system for vehicle accident prevention.

## 📋 Project Overview

- **Objective**: Develop a predictive risk scoring system to reduce accidents by 15-20%
- **Key Features**: 
  - Real-time risk prediction
  - Event-triggered black box
  - Root cause classification
  - Severity grading
  - Multi-sensor fusion

## 🏗️ Tech Stack

- **Backend**: Python (FastAPI)
- **ML**: TensorFlow / PyTorch
- **Frontend**: React.js
- **Database**: PostgreSQL + Redis
- **Deployment**: Docker + AWS

## 📂 Project Structure

See folder structure above - each team member owns their module.

## 🚀 Quick Start

```bash
# Clone repo
git clone <repo-url>
cd risk-score-engine

# Backend setup
cd backend
pip install -r requirements.txt
python app.py

# ML setup
cd ml
pip install -r requirements.txt
python api.py

# Dashboard setup
cd dashboard
npm install
npm start
```
